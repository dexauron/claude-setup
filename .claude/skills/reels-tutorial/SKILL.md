# Рилсы-инструкции из записи экрана

Шаблон и инструменты — в `reels/` в корне репозитория claude-setup
(README там же). Общие приёмы ffmpeg и проверки — в навыке `media-editing`.

## Стиль (из образца пользователя и правил Reels)

Образец — гайд Александра Исакова «Claude теперь сам монтирует reels»
(Claude Code + Remotion). Что берём:
- **Крючок в первые 2–3 с**: результат и выгода крупно («Приходная накладная
  *за 1 клик*»), подпись с цифрой («43 позиции без ручного ввода»).
- **Субтитры**: Montserrat 900, ЗАГЛАВНЫЕ, 1–3 слова на экране (≤20 знаков,
  не больше 2 строк), звучащее слово — акцентным цветом, лёгкий «поп».
- **Тёмный фон**, один акцентный цвет (для 1С — жёлтый `#FFC400`).
- **Каждый шаг**: плашка «Шаг N» + короткая подпись (≤20 знаков — 56px,
  длиннее — 44px), запись в карточке, приближение 1.8–2× к месту действия,
  кольцо на клике.
- **Длина 15–30 с.** Ожидание загрузки, пустые секунды и холостые движения
  мыши вырезаются. Финал — «Сохрани, чтобы не потерять» + подписка.
- **Безопасная зона Reels**: ключевое — между 220px сверху и 380px снизу.
- **Громкость** −14 LUFS; голос — низкий, уверенный, спокойный (так просил
  пользователь).

## Порядок работы

1. **Изучить запись**: `probe.sh`, звук (`volumedetect` — у записей экрана
   дорожка часто пустая), `cropdetect` — где окно программы. Листы кадров
   раз в секунду по области окна, увеличенные 2× — по ним выписать шаги
   с таймкодами.
2. **Точные моменты**: когда что-то появляется (заполнилась таблица,
   открылось меню), проверять долей тёмных пикселей в области, а не на глаз.
   Сцена с результатом начинается ПОСЛЕ появления результата.
3. **Координаты**: кадры с сеткой 10% (`drawgrid=w=iw/10:h=ih/10`) → доли
   кадра для `focus` и `click`.
4. **Текст озвучки**: коротко, разговорно, по одной мысли на шаг. Факты —
   только видимые в записи; чего не видно (что выбрано в выпадающем меню),
   не выдумывать, а спросить пользователя. `say` — для произношения:
   «Штрих-М» → «Штрих Эм», «43» → «сорок три».
5. **plan.json** (формат — `reels/README.md`, пример — `reels/examples/`)
   → `build_reel.py` → `render.sh`.
6. **Проверка до отдачи**: лист кадров результата (наложения, обрезанный
   текст, пустая таблица в начале сцены), `check_sync.py` (медиана −0.1…+0.05 с,
   максимум ≤0.25 с), `probe.sh` (1080×1920, yuv420p), громкость.
   Распознанный текст из `check_sync.py` показывает, какие слова голос
   произносит плохо — их переписать в `say`.
7. **Отдать** через `SendUserFile` и сказать, что в тексте — догадка.

## Голос

- **ElevenLabs** (выбор пользователя): ключ `ELEVENLABS_API_KEY` в настройках
  облачного окружения. Голос подбирает `voice_picker.py search` — русские
  мужские голоса библиотеки, отсортированные по низкому (F0) и ровному тону;
  превью бесплатные. Выбранный — `voice_picker.py add`, его `voice_id` —
  в `plan.json`. Модель по умолчанию `eleven_multilingual_v2` (русский
  поддерживается); `eleven_v4` — новее и эмоциональнее, проверить на пробе.
  Настройки спокойной подачи: stability 0.65, style 0.05, speed 0.95.
- **Piper** — только черновики: русские голоса звучат роботизированно,
  ошибаются в словах (до 14 из 40), а `dmitri` — высокий голос (~188 Гц).
- Свой голос пользователя — тоже вариант: чистка `afftdn`, громкость,
  субтитры через `transcribe.py`.

## Что сказать пользователю о записи (иначе картинка будет мыльной)

- **Захват экрана, а не окна** (OBS: «Захват экрана»): выпадающие меню и
  диалоги — отдельные окна и при захвате окна в запись не попадают.
- **Разрешение записи = разрешению монитора** (OBS → Настройки → Видео:
  базовое и выходное одинаковые, например 1920×1080), 30 fps, качество
  «Неотличимое» или битрейт ≥ 8000 кбит/с. Запись 640×360 непригодна:
  текст 1С в ней не читается ни при каком монтаже.
- **Крупнее интерфейс**: масштаб Windows 125–150% — текст будет читаем
  на телефоне после кадрирования.
- После клика — пауза ~1 с, мышь двигать спокойно. Ждать загрузку можно —
  вырежу.
- Прислать текстом шаги: что нажимаете и зачем, что выбираете в меню.

## Подводные камни (встречены на практике)

- Встроенный браузер Remotion не доверяет сертификату прокси окружения:
  Google Fonts не грузятся. Шрифт — из npm `@fontsource/montserrat`, файлы
  импортируются в сборку (`reels/src/fonts.ts`).
- edge-tts работает через WebSocket — прокси окружения его не пропускает.
- Сайт моделей Vosk (alphacephei.com) закрыт сетевой политикой.
- Silero v5 русские голоса — CC BY-NC (не для коммерции).
- Пропорциональная раскладка слов по слогам отстаёт до 0.4 с — время слов
  брать из ответа ElevenLabs (with-timestamps) или из Whisper по озвучке.
- Одиночное тире в тексте становится отдельной «строкой» субтитров —
  `build_reel.py` приклеивает его к предыдущему слову.
