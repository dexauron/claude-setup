# Домашний сервер

Один скрипт превращает чистую Ubuntu в личный сервер: свои программы
и сайты, файлы с телефона и компьютера, доступ откуда угодно, а ИИ
подключается к серверу и настраивает его сам.

## Быстрый старт: дальше всё делает ИИ

**1. На самом сервере**, за его клавиатурой:

```bash
sudo apt update && sudo apt install -y openssh-server
hostname -I
```

Первый адрес из ответа (вида `192.168.x.x`) — адрес сервера дома.

**2. Подключись по SSH** с компьютера (`ssh auron@АДРЕС`) или с телефона
(приложение Termius). Так команды можно копировать, а не перепечатывать.

**3. Через SSH:**

```bash
echo "$USER ALL=(ALL) NOPASSWD:ALL" > /tmp/nopasswd && sudo visudo -cf /tmp/nopasswd && sudo install -m 440 /tmp/nopasswd /etc/sudoers.d/90-claude-nopasswd
curl -fsSL https://claude.ai/install.sh | bash
~/.local/bin/claude
```

Войди в аккаунт Claude по ссылке, затем набери `/exit`. Дальше:

```bash
sudo apt install -y tmux && tmux new -s claude
~/.local/bin/claude remote-control
```

**4. В приложении Claude Code** появится сессия сервера. Напиши в неё:

> Склонируй github.com/dexauron/claude-setup и запусти server/setup.sh

Первая строка шага 3 разрешает ИИ команды администратора без пароля —
иначе он не сможет настраивать систему. Цена: кто войдёт в твой аккаунт
Claude, получит полный доступ к серверу. Отозвать:
`sudo rm /etc/sudoers.d/90-claude-nopasswd`.

## Или вручную

```bash
git clone https://github.com/dexauron/claude-setup.git
cd claude-setup && bash server/setup.sh
```

Скрипт задаст два вопроса (пароль к папке, права для ИИ) и попросит
войти в Tailscale по ссылке. Запускать повторно безопасно.

## Что ставится

| Что | Зачем |
|---|---|
| Автообновления безопасности | заплатки ставятся сами |
| Docker | свои программы и сайты в контейнерах |
| Папка `/srv/files` (Samba) | файлы с телефона и компьютера |
| Файрвол | из интернета закрыто всё; из дома — SSH и папка; через Tailscale — всё |
| Tailscale | доступ откуда угодно без открытия портов на роутере |
| Claude Code + служба `claude-remote` | сервер всегда виден в приложении Claude Code |

## Как подключаться

На телефон и компьютер поставь Tailscale
([tailscale.com/download](https://tailscale.com/download)) и войди тем же
аккаунтом, что и на сервере. После этого сервер доступен по имени `auron`
из любой сети.

- **Файлы.** Windows: в проводнике `\\auron\files`. Mac: Finder →
  «Подключение к серверу» → `smb://auron/files`. iPhone: «Файлы» → ⋯ →
  «Подключиться к серверу». Android: файловый менеджер с SMB, например
  Material Files.
- **Терминал.** `ssh auron@auron`
- **ИИ.** Приложение Claude Code → сессия сервера. Если её нет:
  `systemctl --user status claude-remote`, а посмотреть, что происходит
  внутри: `tmux -L claude-rc attach` (выйти — Ctrl+B, затем D).

## Важно

- **Docker обходит файрвол.** Порт, опубликованный как `-p 8080:80`,
  открыт всей домашней сети. Публикуй так: `-p 127.0.0.1:8080:80`.
- **Диск один — копии нет.** Важное держи ещё где-то.
- **Свет.** В BIOS включи «Restore on AC Power Loss → Power On», чтобы
  сервер сам включался после отключения электричества.
- **VPN.** Tailscale может пускать трафик телефона через дом — защита
  в чужом Wi-Fi. Для обхода блокировок домашний сервер не поможет:
  выход в интернет всё равно идёт с твоего домашнего адреса.
- **Сайты в интернет** — когда появится первый: через Cloudflare Tunnel
  или проброс порта на роутере.
